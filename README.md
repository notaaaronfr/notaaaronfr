## 🚀 Featured project

<p align="center">
  <a href="https://github.com/notaaaronfr/ship-ready">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=notaaaronfr&repo=ship-ready&theme=tokyonight&hide_border=true&border_radius=12" alt="ship-ready" />
  </a>
</p>

**[ship-ready](https://github.com/notaaaronfr/ship-ready)** is an agent skill that makes AI-written
code production-ready, with proof. One install covers Claude Code, Codex, GitHub Copilot and Gemini CLI.

- 🔒 Locks current behavior with tests before touching anything, then finds and fixes bugs and security holes (OWASP 2025 / CWE Top 25).
- ⚡ Fixes Big-O hot spots, with benchmarks and oracle tests proving nothing changed.
- 🧪 Adds property-based and mutation testing, and computes a READY / NOT READY verdict from evidence.
- 📈 In blind-graded evals, agents scored **0.83 with the skill vs 0.46 without**.

```text
evidence  > confidence     measure it, test it, then call it done
small     > clever         code a new teammate can read on day one
safe      > fast           ship quickly, but never silently break things
users     > technology     the stack serves the outcome, not the other way round
```
